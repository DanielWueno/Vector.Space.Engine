# Reyma.VectorSpace.Engine.Microservice - Instrucciones para agentes

Las reglas del servicio estan en un solo lugar para todos los asistentes de IA:

- Reglas criticas y arquitectura: [.github/copilot-instructions.md](.github/copilot-instructions.md)
- Guias por capa: [docs/constitucion/README.md](docs/constitucion/README.md)

Leer ambos antes de modificar el codigo. Puntos de entrada previstos: instrucciones
de repositorio para GitHub Copilot, `CLAUDE.md` para Claude Code y este archivo para
agentes que soporten `AGENTS.md`. La carga depende de la herramienta y su configuracion;
si no se realiza automaticamente, referenciar las guias en la tarea.
